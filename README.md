# Sign and Symbol

Reading notes and source citations for **Chapter 85: "Sign and Symbol"** of *The Great Books of the Western World Syntopicon* (ed. Mortimer J. Adler, 1952) — the index volume that breaks each of the 102 "Great Ideas" into an outline of sub-topics with citations into the Great Books set.

Each folder below is one sub-topic from Adler's outline and holds that topic's citations and/or excerpted source text.
